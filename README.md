\# MOHCINE-PC-MANAGER



\## Descripción



Herramienta de administración y mantenimiento para equipos Windows desarrollada con PowerShell.



El objetivo principal es automatizar tareas habituales de mantenimiento, organización y diagnóstico del ordenador personal.



\## Funcionalidades previstas



\- Diagnóstico del sistema

\- Análisis de almacenamiento

\- Organización inteligente de archivos

\- Limpieza segura de Windows

\- Gestión de copias de seguridad

\- Comprobación de proyectos Git

\- Generación de informes



\## Tecnologías



\- PowerShell

\- JSON

\- HTML

\- Git

\- GitHub
